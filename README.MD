# Sistema de Gestión de Restaurante

## Autor

GORDON ORTEGA HENRI DANIEL

## Descripción

Este proyecto corresponde a un sistema básico de gestión de restaurante desarrollado con Programación Orientada a Objetos en Python.

El sistema permite registrar productos y clientes, almacenarlos mediante listas y mostrar la información registrada en consola.

## Estructura del proyecto

restaurante_app/
│
├── modelos/
│   ├── producto.py
│   ├── cliente.py
│   └── __init__.py
│
├── servicios/
│   ├── restaurante.py
│   └── __init__.py
│
└── main.py
